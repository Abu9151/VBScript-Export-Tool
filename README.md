# VBA Export Tool

## Overview
Automated script to export all configurations in a SOLIDWORKS Part file as STEP and IGES formats, eliminating manual export processes.

## Features
- Batch export of all configurations
- Supports STEP and IGES formats
- Error handling and logging
- Compatible with SOLIDWORKS 

## Technologies Used
- VBScript
- SOLIDWORKS API
- File management automation

## Business Impact
- Eliminated manual export work
- Reduced processing time by 90%
- Improved file consistency

## How to Use
1. Open SOLIDWORKS with your part file
2. Run the VBScript file
3. All configurations will be exported automatically
